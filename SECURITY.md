# Security

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Report vulnerabilities via [GitHub Security Advisories](https://github.com/kovacszsolt/ai-monitor/security/advisories/new) for this repository, or contact the maintainer through your usual private channel if you already have one.

Include:

- Affected version or commit
- Steps to reproduce
- Impact assessment if known

We will acknowledge receipt and work on a fix as soon as practicable.

## Scope

This policy applies to the open-source code in this repository (desktop app and in-process proxy). Hosted infrastructure operated separately is out of scope unless explicitly documented here later.
